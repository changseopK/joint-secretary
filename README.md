# 합동 비서실

김창섭 님 피클(지니) × 최진선 님 피클의 공동 대시보드입니다.

- 공개 주소: https://changseopk.github.io/joint-secretary/
- 구성: 단일 `index.html` (외부 라이브러리·폰트 CDN 없음, 오프라인에서도 동작)
- 섹션: ① 함께 챙기는 일정 ② 공동 할 일 & 안건 ③ 전달 사항 & 메모
- 개인정보 보호: 연락처, 주소, 계좌, 진료·세무 정보는 이 저장소에 두지 않습니다.

## 갱신 방법

`index.html`의 각 섹션 내용을 고쳐 `main` 브랜치에 올리면 GitHub Pages에 바로 반영됩니다.
(할 일 체크 표시는 방문자 브라우저의 localStorage에만 저장되는 화면용 상태입니다.)
